pol2-agent-ballot

Sealed, auditable ballots for AI agents. Each run below executes the protocol in your browser with real cryptography: Ed25519 signatures, sealed-box encryption to an election key split 2-of-3 among custodians, a SHA-256 hash-chained ledger, and an independent audit that recomputes the result.

    Results

    Monte Carlo runs of the same protocol in Python, with scripted agents. Conformist agents follow a visible majority once it leads by two votes. In the sealed condition nothing is visible before the close, so each ballot carries the agent's own evidence.

    Error bars and bands are Wilson 95% intervals. These are simulations of scripted agents; they show what sealing protects against, not how language-model agents or people behave. A pre-registered protocol for language-model agents is in the repository and has not been run.
